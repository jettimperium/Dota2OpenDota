DOTA 2 PULSE 1.2.1
==================

Приложение для просмотра профиля Dota 2 через OpenDota API:
профиль, последние 20 матчей, статистика героев и карта вардов
в одном окне.

УСТАНОВКА
---------
1. Запустите Dota2Pulse-Setup-1.2.1.exe.
2. Следуйте шагам мастера. Права администратора не нужны.
3. После установки запустите Dota 2 Pulse из меню «Пуск»
   или с ярлыка на рабочем столе.

ПЕРВЫЙ ЗАПУСК
-------------
Введите один из вариантов:
- Steam32 ID (например, 86745912);
- Steam64 ID;
- ссылку на профиль OpenDota, Dotabuff или Stratz.

Приложение запомнит аккаунт. Изменить его можно в любой момент
через кнопку «Настройки».

Если матчи не отображаются, проверьте, что в Dota 2 включена
публикация истории матчей: Настройки -> Социальные -> «Открыть
доступ к истории матчей». OpenDota не может показать данные,
которые скрыты в Steam.

ЧТО ВНУТРИ
----------
- обзор профиля: аватар, ранг, MMR, винрейт, KDA и форма;
- последние 20 матчей с фильтрами «Все / Победы / Поражения»;
- топ-10 героев по количеству матчей и винрейту;
- вкладка «Варды»: точная карта Dota 2 7.41 с вышками,
  лесными лагерями и рекой;
- три темы оформления: изумруд, янтарь, кармин;
- фоновая загрузка и повторные попытки при сбоях сети.

ВАРДЫ
-----
1. Откройте вкладку «Варды» и выберите матч в левой колонке.
2. На точной карте 7.41 появятся установки Observer (жёлтые)
   и Sentry (синие). Также отмечены 22 вышки (включая Tier 4)
   и 28 лесных лагерей: светлые круги — обычные лагеря,
   коричневые спирали — древние.
3. Чипы внизу карты отключают ненужный тип вардов.
4. Галочка «Только активные» и шкала времени показывают,
   какие варды действовали в выбранный момент матча.
5. Список справа показывает время установки и снятия. Нажмите
   на строку, чтобы подсветить вард на карте; наведите курсор
   на маркер, чтобы увидеть подробности.

OpenDota хранит журнал вардов только для разобранных матчей.
Если матч ещё не разобран, нажмите «Запросить парсинг». Это
запускает обработку на стороне OpenDota (обычно несколько минут).
После завершения нажмите «Проверить снова».

УДАЛЕНИЕ
--------
«Параметры» -> «Приложения» -> «Установленные приложения» ->
Dota 2 Pulse -> «Удалить».

Настройки и кеш при удалении не стираются. Если нужно удалить их
полностью, удалите папки:
%LOCALAPPDATA%\Dota2Pulse
%APPDATA%\Dota2Pulse

ВАЖНО
-----
Файлы не подписаны цифровым сертификатом. Windows SmartScreen
может показать предупреждение «Неизвестный издатель». Это обычная
реакция на новое неподписанное приложение, а не вирус.

Приложение не связано с Valve. Данные предоставляет OpenDota API.
