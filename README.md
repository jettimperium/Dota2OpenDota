# Dota 2 Pulse

Десктопная версия консольного скрипта для OpenDota: профиль игрока, последние 20 матчей, статистика героев и карта установки вардов в одном окне.

Для передачи пользователям используйте папку `dist\release`: в ней лежат установщик, portable-архив и контрольные суммы SHA-256.

## Варианты запуска

### Установщик — рекомендуется

`dist\installer\Dota2Pulse-Setup-1.2.1.exe`

- не требует прав администратора;
- устанавливается в профиль текущего пользователя;
- создаёт ярлыки в меню «Пуск» и на рабочем столе;
- удаляется через «Приложения и возможности» Windows;
- подходит для Windows 10 1809+ и Windows 11, 64-bit.

### Portable-архив

`dist\Dota2Pulse-Portable-1.2.1.zip`

Распакуйте в любую папку и запустите `Dota2Pulse.exe`. Установка не нужна. Настройки всё равно сохраняются в профиле Windows, а не рядом с exe.

### Один exe

`dist\Dota2Pulse.exe` — автономный файл, если не нужны ярлыки и деинсталлятор.

### Исходники

Папка `dist\Dota2Pulse_Source_1.2.1` и архив `dist\Dota2Pulse_Source_1.2.1.zip` содержат Python-файлы, ресурсы, скрипты сборки и установщик.

## Первый запуск

Приложение попросит Steam32 ID, Steam64 ID или ссылку на профиль OpenDota / Dotabuff / Stratz. Аккаунт и оформление сохраняются локально.

Каждый пользователь Windows получает собственные настройки, кеш и логи. Один и тот же exe можно запускать нескольким пользователям на одном компьютере.

## Что внутри

- первичная настройка аккаунта и выбор акцентной темы: изумруд, янтарь, кармин;
- обзор профиля: аватар, ранг, MMR, винрейт, KDA, форма;
- последние 20 матчей с фильтрами «Все / Победы / Поражения»;
- топ-10 героев по количеству матчей и винрейту;
- вкладка «Варды»: точная карта Dota 2 7.41 с вышками, лесными лагерями и рекой;
- фильтры по типу вардов, шкала времени и список установок;
- фоновая загрузка, повторные попытки при таймаутах, экран ошибки с повтором;
- кеш аватаров и иконок героев;
- настройки аккаунта и темы прямо из приложения.

## Варды

Вкладка «Варды» использует журналы `obs_log`, `sen_log`, `obs_left_log` и `sen_left_log` из полной карточки матча OpenDota. Показываются только установки выбранного игрока.

Мини-карта использует ровное изображение Dota 2 7.41 сверху: на ней видны река, базы Radiant/Dire и лесные лагеря. Поверх карты отмечены все 22 вышки (включая Tier 4) и 28 нейтральных лагерей; маркеры вардов приподняты над поверхностью и отбрасывают тень. Наведите курсор на башню или лагерь, чтобы увидеть подсказку.

Фон мини-карты — изображение карты Dota 2; права на игровые материалы принадлежат Valve. Оно используется только как схема в некоммерческом клиенте.

- маркеры на карте соответствуют координатам OpenDota (сетка 0..255);
- Observer отображается жёлтым, Sentry — синим;
- фильтры-чипы можно отключать, чтобы оставить только нужный тип;
- галочка «Только активные» и шкала времени показывают варды, действовавшие в выбранный момент;
- список справа сортируется по времени установки; при выборе строки маркер подсвечивается на карте.

OpenDota хранит журнал вардов только для разобранных матчей. Если матч ещё не разобран, приложение предложит отправить запрос на парсинг. Обработка выполняется на стороне OpenDota и обычно занимает несколько минут; после неё нажмите «Проверить снова».

Исходная логика OpenDota сохранена в `dota_api.py`; интерфейс построен на PySide6 (Qt Widgets и layout-менеджеры).

## Запуск из исходников

```powershell
python -m pip install -r requirements.txt
python app.py
```

Можно также запустить `run.bat`.

## Пересборка exe

```powershell
.\build.ps1
```

Готовый файл появится в `dist\Dota2Pulse.exe`.

## Пересборка установщика

1. Установите Inno Setup 6.
2. Соберите exe командой `.\build.ps1`.
3. Запустите `.\build_installer.ps1`.

Готовый установщик появится в `dist\installer\Dota2Pulse-Setup-1.2.1.exe`.

## Где хранятся данные

- настройки: `%LOCALAPPDATA%\Dota2Pulse\Dota2Pulse\settings.ini`
- кеш изображений: `%LOCALAPPDATA%\Dota2Pulse\Dota2Pulse\cache`
- логи: `%APPDATA%\Dota2Pulse\Dota2Pulse\logs\dota2pulse.log`

## Про SmartScreen

Файлы не подписаны цифровым сертификатом. Windows может показать предупреждение «Неизвестный издатель» при запуске установщика или exe. Это не вирус, а стандартная реакция SmartScreen на новые неподписанные приложения.

Чтобы у всех пользователей не было этого предупреждения, нужен сертификат подписи кода (Code Signing Certificate). Без него полностью убрать предупреждение нельзя. Для open-source проектов иногда доступны бесплатные программы подписи (например, SignPath), для закрытого проекта — OV/EV-сертификат.

Приложение не связано с Valve. Данные предоставляет OpenDota API.
